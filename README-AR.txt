ZM Academy — حزمة تطوير المنصة
الإصدار: امتدادات المنصة 1.0 — 26 نوفمبر 2026

هذه الحزمة مبنية على ملفات مشروع ZM Academy المرفقة، وتحافظ على صفحات المشروع وواجهات Worker القديمة. وهي توسعة فعلية قابلة للتشغيل بعد تطبيق migration وإعداد أسرار Cloudflare، لكنها ليست ادعاءً بأن جميع المواصفات الضخمة قد اكتملت أو أن النشر الحي تم.

الملفات الرئيسية:
- index.html / welcome.html: واجهات الموقع العامة.
- login.html / register.html: دخول الطالب وإنشاء الحساب.
- student.html: مساحة الطالب وتفضيلاته وإشعاراته ومساعده واختباراته.
- parent.html: بوابة ولي الأمر، بما في ذلك نتائج الاختبارات المعتمدة.
- admin.html: لوحة الإدارة وإدارات المحتوى والطلاب والطلبات والأمان والإضافات.
- page.html: عرض الصفحات المنشورة من محرر الصفحات.
- worker.js: واجهات API ومنطق الخادم.
- admin-extensions.js / admin-extensions.css: وظائف وتنسيقات أقسام لوحة الإدارة المضافة، بما فيها مكتبة الوسائط الأساسية.
- migrations/0001_platform_extensions.sql: إضافة جداول المنصة الجديدة دون حذف الجداول القديمة.
- tests/: اختبارات وحدات وفحص صياغة HTML وJavaScript والتحقق من قابلية إعادة تشغيل migration.
- docs/: دليل التشغيل والتقرير الفني ونتائج الفحص.

متطلبات التشغيل المحلية:
- Node.js 20 أو إصدار حديث يدعم Web Crypto وnode:test.
- Python 3 لتشغيل اختبار SQLite الخاص بالـmigration.
- Wrangler CLI لإدارة Cloudflare Workers وD1 والنشر.

الفحص المحلي:
1. npm test
2. npm run check
3. npm run check:migrations

النشر:
راجع docs/OPERATIONS-AR.md قبل أي نشر. خذ نسخة احتياطية من D1 أولًا، ثم طبّق migrations، ثم اضبط الأسرار وانشر Worker والملفات الثابتة. لا تستبدل الموقع الحي قبل مراجعة التقرير وتجربة staging.

حدود مهمة:
- لم يتم الاتصال بحساب Cloudflare أو تشغيل migration على قاعدة البيانات الحية أو نشر Worker/Pages في هذه الجلسة.
- لم يمكن جلب آخر commit من GitHub بسبب تعذر DNS في بيئة التنفيذ؛ تم البناء على ZIP المرفق ومراجعة صفحة المستودع العامة.
- أضيفت مكتبة وسائط أساسية للصور وPDF مع بيانات D1 ونشر الصور العامة عبر Worker؛ لا تتضمن قص/تحويل الصور أو فهرسة مجلدات متقدمة.
- الذكاء الاصطناعي يحتاج AI_API_KEY وAI_MODEL ومزودًا متوافقًا؛ لم يتم اختبار اتصال خارجي.
- النسخ الاحتياطي في هذه الحزمة إجراء تشغيلي موثق بتصدير D1، وليس خدمة جدولة نسخ احتياطي تلقائية داخل لوحة الإدارة.
- راجع IMPLEMENTATION-STATUS-AR.txt لمعرفة ما اكتمل وما بقي جزئيًا أو خارج النطاق.
